# Data Visualization with Python

## Overview

This repository contains my practice and learning work on Data Visualization using Python. I learned how to create, customize, analyze, and save different types of charts using Matplotlib.

The goal of this section was to understand how data can be converted into meaningful visual insights that support data analysis and decision-making.
