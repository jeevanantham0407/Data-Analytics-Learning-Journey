# Part 5 – Open-Meteo Weather API

## Overview

This part focuses on working with a real-world weather API using Python.

The Open-Meteo API was used to collect current weather information and understand how real-world API data can be retrieved, processed, and extracted using Python.

## Objectives

* Work with a real-world API
* Send API requests using Python
* Use latitude and longitude parameters
* Receive weather data in JSON format
* Extract values from nested JSON
* Understand real-time API data collection

## API Used

Open-Meteo Weather API

The API provides weather information such as:

* Temperature
* Relative Humidity
* Apparent Temperature
* Precipitation
* Wind Speed

## Practice File

### weather_api.py

The program sends a request to the Open-Meteo API and retrieves current weather information.

The JSON response is converted into Python data and required weather values are extracted for analysis.

## Technologies Used

* Python
* Requests
* JSON
* REST API
* VS Code

Open-Meteo API

## Key Learning

This part provided practical experience with a real-world API and showed how external data can be collected using Python.

Understanding API-based data collection is useful in Data Analytics because many datasets are available through APIs and need to be collected before cleaning, transformation, analysis, and visualization.
