# Real API #1 — JSONPlaceholder

## Overview

This section contains practical API exercises using JSONPlaceholder, a public REST API designed for testing and learning.

## Objective

The objective is to understand how Python communicates with an API, retrieves JSON data, checks HTTP responses, and extracts required information from API responses.

## API Used

JSONPlaceholder

## Concepts Practiced

* API endpoints
* GET requests
* HTTP status codes
* JSON responses
* Python lists
* Python dictionaries
* Data extraction
* Query parameters
* Basic error handling

## Resources Practiced

* Users
* Posts
* Comments

## Python Library

* Requests

## API Workflow

Python → API Endpoint → GET Request → HTTP Response → JSON → Python Data

## Key Learning

API data can be retrieved programmatically using Python. JSON responses can be converted into Python lists and dictionaries, allowing specific fields to be extracted and processed.
