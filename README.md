# 2. Operators

### Concepts Learned
- Performing calculations using arithmetic operators:
  - Addition (`+`)
  - Subtraction (`-`)
  - Multiplication (`*`)
  - Division (`/`)
  - Floor Division (`//`)
  - Modulus (`%`)
  - Exponent (`**`)

- Comparing values using comparison operators:
  - Equal (`==`)
  - Not Equal (`!=`)
  - Greater Than (`>`)
  - Less Than (`<`)
  - Greater/Less Than or Equal (`>=`, `<=`)

- Updating values using assignment operators:
  - `=`
  - `+=`
  - `-=`
  - `*=`
  - `/=`

- Combining conditions using logical operators:
  - `and`
  - `or`
  - `not`

- Checking values inside sequences using membership operators:
  - `in`
  - `not in`

- Comparing object identity using:
  - `is`
  - `is not`
