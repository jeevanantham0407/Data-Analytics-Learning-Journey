# Day 03 – Object-Oriented Programming (OOPs)

## Overview

This repository contains my Day 03 Python practice as part of my Data Analytics Learning Journey.

The focus of this day was understanding the fundamentals of Object-Oriented Programming (OOPs) in Python. I learned how to create classes and objects, protect data using encapsulation, reuse code with inheritance, implement method overriding through polymorphism, and hide implementation details using abstraction. I completed practical programs to strengthen my understanding of these concepts.

---

## Topics Covered

### Class and Object

* Creating Classes
* Creating Objects
* Constructors (`__init__`)
* Instance Variables
* Methods
* Accessing Object Attributes

### Encapsulation

* Private Variables
* Data Hiding
* Accessing Private Members Through Methods
* Updating Object Data
* Protecting Object Data

### Inheritance

#### Single Inheritance

* One Parent → One Child
* Method Reusability

#### Multiple Inheritance

* Multiple Parent Classes
* Reusing Features from More Than One Parent

#### Multilevel Inheritance

* Grandparent → Parent → Child
* Multi-Level Code Reusability

#### Hierarchical Inheritance

* One Parent → Multiple Child Classes
* Shared Parent Methods

### Polymorphism

* Method Overriding
* Runtime Polymorphism
* Same Method with Different Behavior

### Abstraction

* Abstract Classes
* Abstract Methods
* `ABC` Module
* `@abstractmethod`
* Hiding Implementation Details
