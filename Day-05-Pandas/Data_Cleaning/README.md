# Data Cleaning Using Pandas

## Overview

This folder contains my practice and learning materials for data cleaning using Python and Pandas.

Data cleaning is an important step in data analysis because real-world datasets often contain missing values, duplicate records, inconsistent column names, and incorrect data types.

## Topics Covered

- Handling Missing Values
- Identifying Duplicate Values
- Removing Duplicate Records
- Renaming Columns
- Standardizing Column Names
- Changing Data Types

## Key Pandas Functions Used

- `isnull()`
- `sum()`
- `fillna()`
- `duplicated()`
- `drop_duplicates()`
- `rename()`
- `astype()`
- `to_datetime()`

## Learning Objectives

- Identify missing values in a dataset
- Handle numerical and categorical missing values
- Detect and remove duplicate records
- Standardize inconsistent column names
- Convert columns into appropriate data types
- Prepare clean datasets for analysis

## Tools Used

- Python
- Pandas
