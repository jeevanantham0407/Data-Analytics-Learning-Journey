# Connecting Python with SQL

## Overview

This section covers how to connect Python with a MySQL database and execute SQL queries from Python.

The connection was implemented using the `mysql-connector-python` library. This provides a foundation for integrating SQL databases with Python for data analysis.

## Technologies Used

- Python
- MySQL
- mysql-connector-python
- VS Code
- MySQL Workbench

## Topics Covered

### 1. Installing MySQL Connector

Installed the MySQL connector library using pip:

```bash
pip install mysql-connector-python
