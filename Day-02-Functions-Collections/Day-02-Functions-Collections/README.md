# Day 2 – Functions & Collections

## Overview

This repository contains my Day 2 Python practice as part of my Data Analytics Learning Journey.

The focus of this day was understanding how to organize code using functions and work with Python's built-in collection data types such as Lists, Tuples, Sets, and Dictionaries. I also completed a menu-driven Student Record Management System mini project to apply these concepts in a real-world scenario.
